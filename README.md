# research-methods
Repo for methods interactive site

## Find Your Research Method

`index.html` is a self-contained, single-page tool for graduate students in rhetoric and writing studies. It asks what you want to find out and whether you're working with human participants, texts, or both, then recommends a research method and the matching readings from this course.

Open `index.html` directly in a browser (no build step, no server needed), or serve the repo with GitHub Pages.

The reading list comes from `Research Methods Potential Readings.docx`, the source of truth for the citations shown on the page.
